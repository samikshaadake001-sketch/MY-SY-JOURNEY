Day 2
CID:-confidentiality,integrity,availability
confidentiality:only authorized users can access the information
encryption:-converting data to unreadable format
integrity:data cannot be changed without permission
integrity is maintained by hashing and digital signature
hashing is just like digital fingerprint of file
different hash means file is modified
digital signature:its used to check who sent the file and whether it is changed or not
Availability:authorised users can access the data when they need it
availability is maintained by backup,redundant servers,DDoS protection
in backup if one server fails then backup is used 
in redundant there are multiple servers if one fails another works
in DDoS fake traffic is created to make it unavailable



Day 3
Computer Network
a group of computers to share information
types of network are LAN ,MAN ,WAN
LAN(local area network)
it covers small area like a particular building
MAN(metropolitan area network)
it covers area like city
WAN(wide area network)
it covers wide area like world ex. internet

Router:its a device that connects network and send information to correct destination and it decide where internet data should go
Switch:connects the devices within a LAN
modem:it converts the signals so device can communicate over ISP(internet service provider) signals

IP(internet protocol) address:its a unique address of device connected to network
MAC(media access control):its unique physical address given to device by manufacturer

When Google creates its servers, it is assigned IP addresses.

HTTP:it sends plain text like sending letter without envelope
port 80
HTTPS:sending letter with envelope
port 443
The data is encrypted, so even if someone intercepts it, they shouldn't be able to understand its contents without the encryption keys.
That lock means the website is using HTTPS, which relies on TLS (Transport Layer Security). TLS is the modern security protocol that encrypts communication. SSL (Secure Sockets Layer) is the older protocol that TLS replaced, but people still often say "SSL certificate" out of habit.

ports:ip address tell the address of computer while port tell the address of particular server or application
