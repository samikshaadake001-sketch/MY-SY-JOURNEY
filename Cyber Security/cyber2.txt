ipconfig:-it displays computers Your IP Address
Default Gateway (usually your router)
Subnet Mask


IPv4 → Current standard you'll see most often.
IPv6 → Newer version you'll learn more about later.
Subnet Mask helps identify which devices belong to the same network.

ping:-It checks whether another device is reachable over the network and measures how long it takes to get a reply.
TTL stands for Time To Live.
TTL prevents packets from looping endlessly on the internet.

nslookup google.com

DNS Server = A computer that converts a domain name into an IP address.


tracert:-(trace route)
It shows every router (hop) your data passes through before reaching the destination.


netstat(network statistic):-it is used for-
🌐 Active network connections
🚪 Open ports
📡 Listening services
📊 Network statistics

netstat -b :-Show executable/program names (may require Command Prompt as Administrator)
netstat -n:show ports numerically
netstat -an:all listening ports and active connections
